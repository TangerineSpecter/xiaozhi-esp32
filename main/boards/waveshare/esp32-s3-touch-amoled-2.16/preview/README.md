# 录音与文字记录 UI 预览

这是 Waveshare ESP32-S3-Touch-AMOLED-2.16 的浏览器交互原型，用于先确认 480×480
屏幕布局和实体三键交互，再把调整同步到 LVGL 固件。

直接打开 `index.html` 即可使用，不需要安装依赖或启动开发服务器。

## 操作规则

- 上键：菜单向后循环；音量增加 5%。
- 中键短按：打开菜单或确认操作。
- 中键长按 2 秒：返回上一级或关闭菜单。
- 下键：菜单向前循环；音量减少 5%。主界面下模拟切换聆听状态。
- 触摸菜单卡片：直接执行对应操作；音量页可点击或拖动进度条。
- 点击菜单面板外部：返回上一级或关闭菜单。
- 录音和文字记录互斥；启动任一项后菜单立即关闭并回到人物界面。
- 录音或文字记录进行中，只能通过对话按钮（下键）或菜单按钮（中键）结束当前任务。
- 录音和文字记录进行中，上键不会执行其他操作，也不能再次打开菜单。

页面直接引用同级板型目录中的 `room.png`、`neutral.png`、`recording.png` 和
`taking_notes.png`，因此替换固件资源后刷新页面即可看到新效果。
