# 录音与文字记录 UI 预览

这是 Waveshare ESP32-S3-Touch-AMOLED-2.16 的浏览器交互原型，用于先确认 480×480
屏幕布局和实体三键交互，再把调整同步到 LVGL 固件。

直接打开 `index.html` 即可使用，不需要安装依赖或启动开发服务器。

## 操作规则

- 上键短按：菜单向后循环；音量增加 5%。人物主界面长按约 1 秒开始录音，录音中再次长按停止并保存。
- 中键短按：打开菜单或确认操作。
- 中键长按 2 秒：返回上一级或关闭菜单。
- 下键：菜单向前循环；音量减少 5%。主界面下模拟切换聆听状态。
- 触摸菜单卡片：直接执行对应操作；音量页可点击或拖动进度条。
- 触摸菜单左上角“返回”：设置菜单返回人物界面，文件页返回上一级；不需要长按。
- 触摸菜单右上角“关闭”：无论当前在哪一层菜单，都直接回到人物界面。
- 点击菜单面板外部：返回上一级或关闭菜单。
- 文件菜单可进入“播放录音”和“查看记录”；录音列表支持上下选择、中键模拟播放/停止，记录列表支持上下选择并显示内容预览。
- 录音和文字记录互斥；启动任一项后菜单立即关闭并回到人物界面。
- 录音中可通过长按上键、对话按钮（下键）或菜单按钮（中键）结束并保存；文字记录通过下键或中键结束。
- 文字记录进行中长按上键不会开启录音，并提示先结束记录；任一任务进行中都不能再次打开菜单。
- 主界面点击人物头部：只切换到 `petting-preview.png` 静态图，约 1 秒后恢复待命表情；菜单、录音和文字记录进行中不触发摸头。

HTML 文件列表使用三条模拟数据展示布局；硬件端按相同流程读取 TF 卡真实目录，并支持播放录音和查看记录内容。

页面直接引用同级板型目录中的 `room.png`、`neutral.png`、`recording.png` 和
`taking_notes.png`。摸头预览使用原始高清 `petting-preview.png`；固件使用由它等比转换、
居中并贴底的 108×108 `petting.png`。
